inoz — 国土の白模型

inoz は、国が公開しているデータだけで日本のどこにでも立てる WebXR ビューアです。 サーバを持たず、データも保持しません。地形も空中写真も建物も、 開くたびにブラウザが配信元から直接受け取っています。
このページは、そこに関わる四つの権利関係をまとめたものです。

1. 使っているデータ

すべて公開データで、商用利用も認められています。出典の表示が条件です。

2. 言わないこと

ライセンスではありませんが、いちばん先に読んでいただきたい約束です。

言わない言う
浸水予測 / 氾濫シミュレーション / 被害想定水位◯mのときの見え方
ここは安全 / ここは危険（判断を書かない）
ルート案内 / 最短経路見るための道すじ
測量結果 / 正確な標高国土地理院の標高データに基づく表示
この避難場所は安全 / 水位◯mまで持つ市町村が指定した避難場所の名称・所在地と、その点の地面の標高
この建物に逃げれば助かる建物の地面と屋上の標高、公表された想定浸水深の階級、その引き算
水位表示は、指定した標高より低い場所を機械的に塗るだけのものです。水がどこから来るか、 時間とともにどう動くか、排水がどう効くかを一切考えていません。川とつながっていない窪地も塗られます。 堤防は標高データに含まれていません。
低い土地が塗られていないことは、そこが安全であることを意味しません。

避難の判断は、お住まいの自治体のハザードマップをご覧ください。

津波浸水想定の面は、都道府県などが公表した想定区域を階級の色で地形に置いたものです。inoz は計算していません。 指定緊急避難場所の点は市町村の指定で、inoz が足しているのはその点の地面の標高だけです（建物や階の高さではありません）。 建物を指したときの「想定浸水深との差」は、建物の屋上の標高と、公表された階級の上端との引き算で、それ以上の意味は持ちません。

あなたが作ったもの、持ち込んだもの

景色を指す URL、貼り付けたデータ、そこから作られた表示はあなたのものです。inoz は預かりません。

?  国の公開データで再現できるもの（座標・視点・表示状態）   … サーバに届く
#  あなたが持ち込んだデータ                                  … サーバに届かない
ブラウザはフラグメント（# より後ろ）をサーバに送りません（HTTP の仕様）。 「貼り付けたデータは送信されません」は、約束ではなく構造です。 そもそも inoz にはサーバがありません。

ただし、そこから作った画像や動画を配る場合、1. の出典表示の義務はあなたに引き継がれます。 「国土地理院」「Project PLATEAU（国土交通省）」の表示を添えてください。

5. 計測

来訪数だけを数えています(GoatCounter)。

送っているのは「/」という固定のパスと「inoz」という固定の題名の2つだけです。 あなたが立っている座標(URL の ? 以降)も、持ち込んだデータ(# 以降)も、参照元も送りません。 スクリプトではなく 1×1 の画像で数えているので、外部の JavaScript はこのページに一つもありません。
取れるのは「何人来たか」だけで、「どこを見たか」は取れません。それでよいと決めました。
